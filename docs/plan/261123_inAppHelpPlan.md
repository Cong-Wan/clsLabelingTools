## 1. 背景与问题

用户首次进入 Web 界面后不知道怎么用。现状盘点（证据）：

| 位置 | 现有说明 | 问题 |
|---|---|---|
| 首访引导（app.js showNameGuide） | 仅设置显示名，可跳过 | 不含任何操作说明 |
| 任务列表页（taskView.js） | 表单 placeholder + 标签映射一行小字 | 创建流程、来源二选一差异、上传等待、删除规则均无说明 |
| 标注页（labelView.js） | 无 | 热键 1-9/0/←/→、三态点、过滤、自动前进全靠用户自己猜 |
| README.md | 完整 | 用户在浏览器里看不到 |

## 2. 目标

1. 顶栏常驻「使用说明」按钮，任务列表页与标注页均可打开帮助弹窗；
2. 帮助弹窗内容完整覆盖操作路径：快速上手（4 步）、快捷键表、创建任务（两种来源+限制+标签规则）、任务状态含义、标注页操作（三态/过滤/跳转/自动前进）、保存与失败重试、导出与多人合并、常见问题；
3. 首访引导弹窗增加「查看使用说明」入口；
4. 帮助弹窗打开期间屏蔽标注热键（防止按 1-9 误标注），支持 ESC / 点遮罩 / 关闭按钮三种关闭方式；
5. 保持零框架、零 CDN、零构建，匹配现有经典脚本风格（IIFE、var、字符串拼接）。

## 3. 设计

### 3.1 交互与结构

- 顶栏（index.html 静态结构，视图切换只重渲染 `#viewRoot`，顶栏不受影响）：`annotatorSlot` 之后追加 `<button id="helpBtn" class="btn-mini">使用说明</button>`，app.js `start()` 时绑定一次；
- 弹窗结构：`.help-overlay`（遮罩，点击关闭）> `.help-box` > `.help-head`（标题+× 关闭按钮）+ `.help-body`（滚动内容，各小节 h4 + 表格/列表）；
- 关闭方式：× 按钮、ESC 键、点击遮罩空白区（overlay 处理器须判 `e.target === overlay`，box 内点击不得误关）；ESC 监听在 helpView 模块初始化时挂一次（IIFE 内直接 addEventListener），处理器内先判 `isOpen()`，避免多次开关叠加监听器；
- 层级：`guide-overlay` z-index 90 → help-overlay 取 95，toast 保持 100 最顶；
- 热键守卫：app.js `attachKeyboard` 处理器最前面加 `if (window.clsHelpView && clsHelpView.isOpen()) return;`——弹窗打开时 1-9/0/←/→ 不再触发标注/导航；
- 首访引导：`guide-btns` 追加第三个按钮「查看使用说明」——点击后完成引导（写 LS_NAME_GUIDE、移除 overlay、刷新顶栏名字）再打开帮助弹窗；改名入口不丢（顶栏名字随时可点）。

### 3.3 帮助内容初稿（信息架构，事实已逐条对照代码）

弹窗小节顺序与内容如下（正文措辞以实现时为准，事实口径以此为准）：

**① 快速上手**
1. 任务列表页「创建任务」：填任务名 → 选数据来源（服务器绝对路径 / 上传压缩包）→ 添加标签类别 → 点「创建任务」；
2. 等任务状态变「就绪」（状态会自动更新，处理完成自动变「就绪」；大压缩包整个上传+处理过程需分钟级）；
3. 点「打开」进标注页：看图 → 按数字键 1-9（或点击类别按钮）→ 自动跳下一张；
4. 标完点「导出 CSV」下载结果。

**② 键盘快捷键（标注页）**

| 键 | 作用 |
|---|---|
| 1 ~ 9 | 给当前图片打对应类别标签，并自动跳到下一张 |
| 0 | 清除当前图片标注（停留当前张） |
| ← / → | 上一张 / 下一张 |

补充：每张图只能有**一个类别（单标签）**——按另一个数字键（或点其他类别按钮）会直接**覆盖**原标注；光标在输入框（如跳转框）内时快捷键不生效；第 10 个及之后的类别没有热键，只能点击选择。

**③ 创建任务**
- 任务名称 ≤64 字符；
- 数据来源二选一：
  - **服务器绝对路径**：服务器本机可读的目录，自动递归扫描其中的图片（jpg/jpeg/png/bmp/webp/gif）。适合数据已在服务器上的情况，无需上传等待（数据量大时扫描在后台进行，稍候即可）；
  - **压缩包上传**：支持 .zip / .7z / .rar。进度条走完后还会显示「服务器保存中…」，GB 级大包整个上传+保存过程约需**分钟级**，属正常等待。限制：单包 ≤10GB；解压后总量 ≤20GB、文件数 ≤20 万；**不支持加密包、分卷包；压缩包内的压缩包不会被解压**（嵌套包会导致「未发现支持的图片文件」）；
- **标签映射**：在「输入类别名称」框里输入一个类别名，点「添加」（或按回车）**逐个添加**；类别名 ≤32 字符、最多 50 个，同名自动去重，点类别右侧的「×」可删除。**数字热键按添加顺序分配：第 1 个添加的对应 1，第 2 个对应 2 … 前 9 个对应数字键 1-9，之后仅点击**；删除中间类别后，后面的类别自动补位（热键号随之变化）。**创建后不可修改**——要改标签必须删除任务重建。

**④ 任务状态**
- 解压中 / 扫描中：后台处理中，页面自动刷新，完成自动变「就绪」；
- 就绪：可打开标注、可导出 CSV；
- 错误：卡片显示红色原因；常见为压缩包不支持（加密/分卷/嵌套）或路径不存在，删除后重建即可。

**⑤ 标注页**
- 顶栏工具行：返回 / 过滤（全部 / 未标注 / 已标注）/ 序号跳转 / 导出 CSV；
- 右侧列表：上方「上一页 / 下一页」翻页（每页 100 张），圆点颜色即状态——**绿=已保存，黄=保存中/待确认（含失败待重试），灰=未标注**；按数字键后该图立刻变黄，保存成功后在下一次操作或刷新时转绿。点击任意行跳到该图；
- 标注页下方类别按钮可直接点击（无需键盘），「清除」按钮=数字键 0 的鼠标等价操作；
- 标注后自动前进（在当前过滤列表内顺序，跨页自动加载，最后一张停留提示）；「未标注」过滤下标注后该项移出列表，适合连续快打；
- 保存机制：标注后**立即自动保存**（无需任何手动保存操作），顶栏同步显示「保存中… / 已保存 时间 / N 条待重试」；网络失败自动重试 1 次，仍失败进「N 条待重试」，点「一键重试」或刷新页面自动补传，**数据不丢**；
- 顶栏右上角名字=标注人显示名（点击可改），导出 CSV 的 annotatorName 列使用它。

**⑥ 导出与多人协作**
- 「导出 CSV」仅「就绪」任务可用：浏览器下载完整 CSV（列：relPath, absPath, label, annotatorId, annotatorName, updatedAt；未标注行 label 为空），服务器 exports/ 同步留档；
- 两人标同一批数据：各自导入同一数据源、各建各的任务，互不可见；两份 CSV 的 relPath 一致，可用 Excel 按 relPath 列 VLOOKUP 合并。

**⑦ 常见问题**
- 上传进度 100% 后停在「服务器保存中…」？正常，GB 级包写盘需分钟级；
- 任务报「未发现支持的图片文件」且图片在压缩包里的压缩包里？先手动解压外层包，再走「绝对路径」导入，或直接上传内层 zip；
- 换浏览器/清缓存后任务不见了？身份绑定浏览器（匿名 clientId），换浏览器=新身份，请回原浏览器操作；
- 删除任务后磁盘文件还在？删除仅清数据库记录，物理文件保留（防误删），需手动清理；
- 处理中任务删不掉？页面会二次确认「强制删除」（中断后台处理）；
- 服务重启后任务变「错误」？中断任务删除后重建即可。

### 3.4 技术要点与风格约束

- helpView.js 匹配现有代码风格：IIFE + `'use strict'` + `var` + 字符串拼接 HTML + `window.clsHelpView` 导出；静态内容无需转义（纯自家 HTML）；
- 加载顺序：api.js → **helpView.js** → app.js → taskView.js → labelView.js（app.js 的绑定与守卫在运行期引用 clsHelpView，脚本引入顺序保证定义先于使用）；
- 弹窗尺寸：max-width 720px、max-height 85vh，help-body 独立滚动；小屏（移动端）max-width 92vw 兜底；
- 打开帮助时若首访引导 overlay 仍在：帮助入口在引导框内，不存在二者叠加路径（引导完成后才开帮助）。

### 3.5 明确不做

- 不做分步 tour / 聚焦高亮式新手引导（成本高、与当前零依赖架构不匹配）；
- 不改动任何现有交互逻辑与后端（纯增量说明层）；
- 不做 i18n / 多语言；
- 不在任务页/标注页内嵌大段常驻说明（避免挤占操作区），统一收敛到帮助弹窗。
